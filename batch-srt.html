字幕工作流

在本地批量把视频转成 SRT

在大嘴鸟字幕中选择「仅转写」并准备 Whisper 权重后，即可在本机批量处理视频目录，导出带时间码的 SRT。这个流程不需要 Ollama 或 API 密钥。

示例：一个课程视频文件夹

假设你有三段课程视频，其中一段很长。先用一段短视频确认所选 Whisper 模型能识别素材语言，再把整个文件夹加入队列。这个例子用于说明操作流程。

  1. 在「设置 → 语音转写」选择引擎和 Whisper 模型并下载权重。关闭需要远程服务的精修和翻译，选择「仅转写」。
  2. 回到工作台，选择「添加目录（含子目录）」。如果目录已有字幕，检查是否打开了「跳过已有字幕的视频」，以免把跳过的文件误判为处理失败。
  3. 点击「开始批量提取」，在队列里查看进度。任务完成后，在媒体所在目录查看 SRT，抽查首尾字幕和关键片段的时间码。

长视频中断后如何继续

重开应用并查看恢复的队列。从任务的更多菜单选择「继续处理（保留已完成片段）」，然后再次开始批量提取。继续处理会复用兼容检查点。更换媒体文件、源语言或主模型时，按提示确认恢复或重做。选择重新开始会清除此任务的检查点。
