字幕翻译

用 Ollama 或自备 API 翻译字幕

大嘴鸟字幕先在本机用 Whisper 转写音视频，再用你配置的模型翻译字幕。应用保留转写时间轴，把处理后的文字对应回字幕条目。安装包不内置大语言模型。

查看配置步骤 ↗下载 ↗
路径一：使用本机 Ollama路径二：使用远程 API对照同一时间轴

路径一：使用本机 Ollama

安装并启动 Ollama，再下载所选模型。在大嘴鸟字幕中选「翻译字幕」，服务选本机 Ollama，填写模型名称并选择目标语言。使用本机服务时，字幕文本留在本机。

路径二：使用远程 API

在「翻译字幕」设置中选择 OpenAI 兼容服务，填写服务地址、模型名称和自备 API 密钥，选择目标语言。字幕文本会发往所配置的端点，费用和留存取决于服务方。

双语预览与 SRT 输出

应用可以在同一时间轴预览原文与译文。翻译时保留「输出原语音字幕」即可获得原文和译文两个 SRT。关闭该设置时，只保留最终译文输出。下方两个示例文件时间码相同，供你分别在剪辑或播放工具中查看。

1
00:00:00,000 --> 00:00:04,000
清晨，我们沿着街道慢慢走。
1
00:00:00,000 --> 00:00:04,000
Early in the morning, we take a slow walk down the street.
