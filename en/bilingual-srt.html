Translate subtitles

Translate subtitles with Ollama or your own API key

Toucan Subtitle transcribes the media locally with Whisper, then uses a model you configure to translate the subtitle text. The app retains the transcription timeline and matches the translated text to its cues. The installer does not bundle a large language model.

Option 1: Local Ollama

Install and start Ollama, then download your chosen model. In Toucan Subtitle, select subtitle translation, choose local Ollama, enter the model name and select a target language. With a local service, the subtitle text stays on your computer.

Option 2: Remote API

In translation settings, select an OpenAI-compatible service, enter its endpoint URL, model name and your own API key, then choose a target language. Subtitle text goes to that endpoint. Fees and retention depend on your provider.

Bilingual preview and SRT output

The app previews original and translated text on the same timeline. Keep the original-subtitle output enabled to get separate source and translated SRT files. Turn it off to keep only the final translation output. The two illustrative files below use matching timecodes.
