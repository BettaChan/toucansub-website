1.2.02

2026-11-12
Internal candidate

Package size, licensing and runtime

  • Reduced runtimes on both platforms while retaining transcription and diagnostics.
  • Added the app licence and third-party notices, and prepared corresponding FFmpeg source materials.
  • Windows x64 uses the system Visual C++ x64 runtime and includes engine diagnostics.
  • The queue sits above job details, and the log panel can collapse to the right.

GitHub Actions verified candidate checksums and archive integrity. A GitHub Windows x64 runner passed installation, launch, offline diagnostics and transcription of real audio. Physical Windows hardware testing and release signing are pending. Public installers are not yet available.
