Features

One app, three subtitle workflows.

Choose how to process your media based on the output you need. Speech recognition runs locally. Polishing and translation use your configured model.

Job workspace

Manage multiple files in one view.

  • Add files or folders and process them in a queue.
  • See transcription, translation progress and subtitle previews.
  • Long jobs run in chunks and can resume from compatible checkpoints.
  • Check resource status, quality warnings and logs.

Models and health checks

Configure speech and language models separately.

No large language model is bundled with the app. To polish or translate subtitles, install Ollama and download a model, or supply your own API key for an OpenAI-compatible cloud service.

Transcription uses separately downloaded Whisper weights and requires neither Ollama nor an API key.

Check the runtime, engine, weights and language model in Settings.
