Installer l’application

Consultez le centre de téléchargement pour connaître les plateformes et versions disponibles. Téléchargement ↗

macOS Apple Silicon

Ouvrez le DMG obtenu et glissez l’application dans Applications, ou décompressez le ZIP et déplacez-la dans ce dossier.

Windows x64

Lancez le programme EXE ou décompressez entièrement le ZIP avant de lancer l’application. Installez ou réparez Visual C++ x64 si Windows le demande.

Télécharger l’environnement Microsoft ↗

Vérifier les fichiers

Remplacez le nom de fichier d’exemple et comparez le résultat avec la liste SHA-256 du même GitHub Release.

macOS

shasum -a 256 "installer.dmg"

Windows PowerShell

Get-FileHash "installer.exe" -Algorithm SHA256

Préparer les modèles

  1. Dans Réglages → Transcription, choisissez le moteur et la taille du modèle.
  2. Téléchargez le modèle et attendez la fin du téléchargement.
  3. Vérifiez l’environnement, le moteur et les poids dans le diagnostic.

Configurer un modèle de révision ou de traduction

L’application n’inclut aucun grand modèle de langage. Pour réviser ou traduire des sous-titres, installez Ollama et téléchargez un modèle, ou fournissez votre propre clé API pour un service cloud compatible OpenAI.

Renseignez le nom du modèle pour Ollama en local. Pour un service compatible OpenAI, indiquez URL de base, clé API et nom du modèle. Whisper suffit pour transcrire.

La transcription utilise des poids Whisper à télécharger séparément et ne nécessite ni Ollama ni clé API.

Créer les sous-titres

  1. Revenez à l’espace de travail et ajoutez les fichiers ou dossiers.
  2. Choisissez transcription, révision ou traduction. En traduction, sélectionnez la langue cible.
  3. Lancez le lot et suivez la progression. Confirmez la langue réelle si demandé.
  4. Vérifiez l’aperçu, puis récupérez le SRT dans le dossier du média.

Données et confidentialité

Transcription locale

La lecture des médias, l’extraction audio et Whisper s’exécutent sur l’ordinateur. Le premier téléchargement des poids nécessite Internet.

Où s’effectuent la révision et la traduction

Le texte est envoyé au service configuré. Ollama local traite le texte sur l’ordinateur. Un service distant applique ses propres règles de traitement et de conservation.

Démo du site

La page d’accueil utilise un exemple fixe et ne permet pas l’envoi de médias.

Questions fréquentes

Faut-il Ollama pour transcrire ?

Choisissez la transcription seule et téléchargez les poids Whisper requis.

Que faire si Windows signale un environnement manquant ?

Vérifiez Visual C++ x64. Le fichier support/diagnose-engine.cmd dans le dossier de l’application vérifie les dépendances.

Comment reprendre une tâche interrompue ?

Rouvrez l’espace de travail et vérifiez la file restaurée. Les points de reprise compatibles sont réutilisés. Si un modèle, une langue ou un fichier a changé, suivez l’invite affichée.

Que vérifier si la tâche se termine avec un avertissement ?

Vérifiez les signalements, les passages incertains, les textes conservés dans la langue source et les dialogues importants.

Comment signaler un problème ?

Indiquez l’architecture, la version, l’étape et la procédure de reproduction. Retirez les noms de fichiers, chemins, sous-titres et clés des journaux. GitHub Issues ↗
