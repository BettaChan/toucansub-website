使用指南

生成你的 第一份字幕。

安装应用，准备 Whisper 模型，然后导入音频或视频。

安装应用校验文件准备模型生成字幕数据与隐私常见问题

安装应用

在下载中心查看支持的平台和版本状态。 下载 ↗

macOS Apple Silicon

取得发行包后，打开 DMG 并将应用拖入「应用程序」，或解压 ZIP 后将应用移入「应用程序」。

Windows x64

运行 EXE 安装程序，或将 ZIP 完整解压后启动「大嘴鸟字幕.exe」。如系统提示缺少 Visual C++ x64 运行库，请安装或修复。

微软官方运行库下载 ↗

校验文件

将命令里的文件名替换为实际文件名，并与同一 GitHub Release 的 SHA-256 清单比对。

macOS

shasum -a 256 "installer.dmg"

Windows PowerShell

Get-FileHash "installer.exe" -Algorithm SHA256

准备模型

  1. 打开「设置 → 语音转写」，选择引擎和模型大小。
  2. 点击「下载转写模型」，等待权重下载完成。
  3. 打开「健康度检查」，确认运行环境、引擎和权重可用。

配置精修与翻译模型

安装包不内置大语言模型。 字幕精修和翻译需要自行安装 Ollama 并下载模型，或自备支持 OpenAI 兼容接口的云端服务 API 密钥。

选择本地 Ollama 并填写模型名，或为 OpenAI 兼容服务填写 Base URL、API Key 和模型名。仅转写只需 Whisper。

仅转写使用另行下载的 Whisper 权重，无需 Ollama 或 API 密钥。

生成字幕

  1. 返回工作台，添加文件或目录。
  2. 选择仅转写、精修原文或翻译字幕，翻译时选择目标语言。
  3. 开始批次并查看进度。若提示确认源语言，请选择素材的实际语言。
  4. 完成后检查字幕预览，到媒体所在目录查看 SRT。

数据与隐私

本机转写

应用在电脑上读取素材、抽取音频并运行 Whisper。首次下载权重需要联网。

精修和翻译的服务边界

字幕文本发送到你配置的模型端点。本机 Ollama 在本机处理，远程服务的处理和留存取决于服务方。

常见问题

只提取原文字幕，需要 Ollama 吗？

选择「仅转写」，下载所需 Whisper 权重后即可使用。

Windows 提示运行库缺失怎么办？

检查 Visual C++ x64 运行库。应用目录中的 support/diagnose-engine.cmd 可检查引擎依赖。

如何继续中断的任务？

重新打开工作台，查看恢复的队列。应用会复用兼容断点。更改模型、源语言或文件后，按提示确认恢复或重做。

看到「完成 ⚠」时该检查什么？

查看质量标记、未可靠识别的片段、仍保留原文的条目及关键对白。

如何反馈问题？

提供系统架构、应用版本、任务阶段和复现步骤。提交日志前请移除素材名称、路径、字幕文本和密钥。 GitHub Issues ↗
