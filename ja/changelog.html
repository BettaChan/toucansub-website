正式版 1.2.02

サイズ、ライセンス、実行環境

  • 音声認識と診断を残し、両 OS の実行環境を小型化。
  • アプリライセンスと第三者通知を追加し、FFmpeg 対応ソースを整理。
  • Windows x64 はシステムの Visual C++ ランタイムを使用し、エンジン診断を追加。
  • キューを詳細の上に移し、ログを右に折りたためるように変更。
  • 「ヘルプ → このアプリについて」に手動更新確認を追加しました。

macOS 版はアドホック署名済みで、Apple の公証は未取得です。 Windows パッケージはテスト済みで、署名はありません。
