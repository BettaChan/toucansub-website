使い方

初めての 字幕作成。

アプリを導入し、Whisper を準備して、動画や音声を追加します。

アプリを導入ファイルを確認モデルを準備字幕を作成データとプライバシーよくある質問

アプリを導入

ダウンロードページで対応環境とバージョン状況を確認してください。 ダウンロード ↗

macOS Apple Silicon

入手した DMG を開いてアプリケーションフォルダーに移すか、ZIP を展開して移してください。

Windows x64

EXE を実行するか、ZIP をすべて展開してアプリを起動してください。Visual C++ x64 が不足している場合はランタイムを導入または修復します。

Microsoft ランタイム ↗

ファイルを確認

コマンドのファイル名を変更し、同じ GitHub Release の SHA-256 一覧と照合してください。

macOS

shasum -a 256 "installer.dmg"

Windows PowerShell

Get-FileHash "installer.exe" -Algorithm SHA256

モデルを準備

  1. 設定の音声文字起こしでエンジンとモデルサイズを選びます。
  2. モデルをダウンロードし、完了を待ちます。
  3. 動作チェックで実行環境、エンジン、重みを確認します。

整文・翻訳用モデルの設定

アプリに大規模言語モデルは同梱されていません。 字幕の整文・翻訳には、Ollama をインストールしてモデルを取得するか、OpenAI 互換のクラウドサービスの API キーを用意してください。

ローカル Ollama ではモデル名を入力します。互換サービスには Base URL、API キー、モデル名が必要です。文字起こしのみなら Whisper で十分です。

文字起こしには別途取得する Whisper の重みを使用し、Ollama や API キーは不要です。

字幕を作成

  1. 作業画面でファイルやフォルダーを追加。
  2. 文字起こし、整文、翻訳を選びます。翻訳では訳先の言語を指定します。
  3. 一括処理を開始し、必要に応じて素材の言語を確認します。
  4. プレビューを確認し、素材フォルダーで SRT を取得します。

データとプライバシー

ローカル文字起こし

素材の読み込み、音声抽出、Whisper 実行は PC 上で行います。最初の重みの取得にはインターネットが必要です。

整文・翻訳の処理先

字幕テキストは設定したサービスに送信されます。ローカル Ollama は PC 上で処理し、外部サービスは提供元の処理・保存規定に従います。

ウェブデモ

ホームのデモは固定サンプルで、素材アップロード機能はありません。

よくある質問

文字起こしだけでも Ollama が必要ですか？

文字起こしのみを選び、Whisper の重みを取得してください。

Windows でランタイム不足と表示されたら？

Visual C++ x64 を確認してください。アプリ内の support/diagnose-engine.cmd で依存関係を確認できます。

中断した処理はどう再開しますか？

作業画面を再度開いてキューを確認します。互換性のある中断点を再利用します。モデル、言語、ファイルを変更した場合は画面の案内に従ってください。

警告付きで完了した場合は？

品質マーク、不確かな箇所、原文のままの項目、重要な台詞を確認してください。

不具合はどこに報告しますか？

環境、版、処理段階、再現手順を添えてください。ログのファイル名、パス、字幕、キーは削除してください。 GitHub Issues ↗
