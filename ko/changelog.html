패키지 크기, 라이선스와 실행 환경

  • 음성 인식 및 진단을 유지하고 두 플랫폼의 런타임을 줄였습니다.
  • 앱 라이선스와 제3자 고지를 추가하고 FFmpeg 대응 소스 자료를 정리했습니다.
  • Windows x64에서 시스템 Visual C++ 런타임을 사용하고 진단을 추가했습니다.
  • 대기열이 작업 상세 위에 있고 로그는 오른쪽으로 접힙니다.
  • 도움말의 정보 화면에서 수동으로 업데이트를 확인할 수 있습니다.

macOS 앱은 애드혹 서명되었으며 Apple 공증은 아직 받지 않았습니다. Windows 패키지는 테스트를 마쳤으며 서명되지 않았습니다.
