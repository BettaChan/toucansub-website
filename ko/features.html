작업 공간

여러 파일을 한 화면에서 관리하세요.

  • 파일이나 폴더를 대기열에 추가합니다.
  • 진행 상황과 자막 미리보기를 확인합니다.
  • 긴 작업은 구간으로 나누고 호환 지점부터 재개합니다.
  • 리소스, 품질 알림 및 로그를 확인합니다.

모델과 상태 점검

음성 인식 모델과 언어 모델을 별도로 설정하세요.

앱 설치 패키지에 대규모 언어 모델은 포함되지 않습니다. 자막을 다듬거나 번역하려면 Ollama를 설치해 모델을 다운로드하거나 OpenAI 호환 클라우드 서비스의 API 키를 직접 준비하세요.

음성 인식에만 사용하는 Whisper 가중치는 별도로 다운로드하며 Ollama나 API 키는 필요하지 않습니다.

설정에서 실행 환경, 엔진, 가중치와 모델을 점검합니다.
