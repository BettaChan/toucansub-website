사용 안내

첫 자막을 만들어 보세요.

앱을 설치하고 Whisper 모델을 준비한 뒤 음성이나 영상을 가져옵니다.

앱 설치파일 검증모델 준비자막 생성데이터 및 개인정보자주 묻는 질문

앱 설치

다운로드 센터에서 지원 플랫폼과 버전 상태를 확인하세요. 다운로드 ↗

macOS Apple Silicon

DMG를 열어 앱을 응용 프로그램 폴더로 옮기거나 ZIP을 푼 후 같은 폴더로 옮기세요.

Windows x64

EXE 설치 프로그램을 실행하거나 ZIP을 모두 푼 뒤 앱을 실행하세요. Visual C++ x64가 없다는 메시지가 나오면 런타임을 설치하거나 복구하세요.

Microsoft 런타임 다운로드 ↗

파일 검증

명령의 예제 파일 이름을 실제 이름으로 바꾸고 같은 GitHub Release의 SHA-256 목록과 비교하세요.

macOS

shasum -a 256 "installer.dmg"

Windows PowerShell

Get-FileHash "installer.exe" -Algorithm SHA256

모델 준비

  1. 설정 → 음성 인식에서 엔진과 모델 크기를 선택합니다.
  2. 음성 인식 모델을 다운로드하고 완료될 때까지 기다립니다.
  3. 상태 점검에서 실행 환경, 엔진과 가중치를 확인합니다.

다듬기 및 번역용 모델 설정

앱 설치 패키지에 대규모 언어 모델은 포함되지 않습니다. 자막을 다듬거나 번역하려면 Ollama를 설치해 모델을 다운로드하거나 OpenAI 호환 클라우드 서비스의 API 키를 직접 준비하세요.

로컬 Ollama의 모델 이름을 입력합니다. OpenAI 호환 서비스에는 기본 URL, API 키와 모델 이름이 필요합니다. 음성 인식만 할 때는 Whisper면 충분합니다.

음성 인식에만 사용하는 Whisper 가중치는 별도로 다운로드하며 Ollama나 API 키는 필요하지 않습니다.

자막 생성

  1. 작업 공간에서 파일이나 폴더를 추가합니다.
  2. 음성 인식, 원문 다듬기 또는 번역을 선택합니다. 번역 시 대상 언어를 지정합니다.
  3. 일괄 작업을 시작하고 진행률을 확인합니다. 메시지가 나오면 실제 원어를 지정합니다.
  4. 미리보기를 검토하고 미디어 폴더에서 SRT를 찾습니다.

데이터 및 개인정보

로컬 음성 인식

앱은 컴퓨터에서 파일을 읽고 오디오를 추출한 뒤 Whisper를 실행합니다. 첫 가중치 다운로드에는 인터넷이 필요합니다.

다듬기와 번역의 처리 위치

자막 텍스트는 설정한 서비스로 전송됩니다. 로컬 Ollama는 컴퓨터에서 처리하며 원격 서비스의 처리와 보관은 제공자 정책에 따릅니다.

웹사이트 데모

홈에는 고정된 예제가 있으며 미디어 업로드는 제공하지 않습니다.

자주 묻는 질문

원어 자막만 만들 때도 Ollama가 필요한가요?

음성 인식만 선택하고 필요한 Whisper 가중치를 다운로드하세요.

Windows가 런타임이 없다고 표시하면 어떻게 하나요?

Visual C++ x64를 확인하세요. 앱 폴더의 support/diagnose-engine.cmd로 엔진 의존성을 점검할 수 있습니다.

중단된 작업은 어떻게 재개하나요?

작업 공간을 다시 열어 복원된 대기열을 확인하세요. 모델, 언어 또는 파일이 바뀌었다면 화면 안내에 따라 재개하거나 다시 시작하세요.

작업이 경고와 함께 완료되면 무엇을 확인하나요?

품질 표시, 불확실한 구간, 원문이 남은 항목과 중요한 대사를 확인하세요.

문제는 어떻게 보고하나요?

시스템 아키텍처, 앱 버전, 작업 단계와 재현 방법을 알려 주세요. 로그에서 미디어 이름, 경로, 자막과 키를 제거하세요. GitHub Issues ↗
