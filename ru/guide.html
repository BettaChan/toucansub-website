Установка

Проверьте поддерживаемые платформы и статус версии на странице загрузки. Скачать ↗

macOS Apple Silicon

Откройте полученный DMG и перенесите приложение в «Программы» либо распакуйте ZIP и перенесите приложение туда.

Windows x64

Запустите установщик EXE или полностью распакуйте ZIP и запустите приложение. Если Windows сообщает об отсутствии Visual C++ x64, установите или восстановите этот компонент.

Скачать компонент Microsoft ↗

Проверка файлов

Подставьте имя своего файла и сравните результат со списком SHA-256 из того же выпуска GitHub.

macOS

shasum -a 256 "installer.dmg"

Windows PowerShell

Get-FileHash "installer.exe" -Algorithm SHA256

Подготовка моделей

  1. Выберите движок и размер модели в настройках распознавания.
  2. Скачайте модель и дождитесь завершения.
  3. В диагностике проверьте среду, движок и веса.

Модель для редактуры или перевода

Для Ollama укажите имя модели. Для совместимого сервиса введите базовый URL, ключ API и имя модели. Для распознавания достаточно Whisper.

Создание субтитров

  1. Вернитесь в рабочую область и добавьте файлы или папки.
  2. Выберите распознавание, редактуру или перевод. Для перевода выберите целевой язык.
  3. Запустите очередь и следите за прогрессом. При запросе подтвердите исходный язык.
  4. Проверьте предпросмотр и найдите SRT рядом с исходным файлом.

Данные и конфиденциальность

Локальное распознавание

Приложение читает файлы, извлекает звук и запускает Whisper на вашем компьютере. Для первой загрузки весов нужен интернет.

Где выполняются редактура и перевод

Текст отправляется на настроенный адрес. Локальный Ollama обрабатывает его на компьютере. Удалённый сервис применяет свои правила обработки и хранения.

Демо на сайте

На главной странице используется готовый пример, загрузки материалов нет.

Частые вопросы

Нужен ли Ollama для исходных субтитров?

Выберите только распознавание и скачайте веса Whisper.

Что делать, если Windows не находит компонент среды?

Проверьте Visual C++ x64. Файл support/diagnose-engine.cmd в папке приложения проверяет зависимости движка.

Как продолжить прерванную задачу?

Откройте рабочую область и проверьте восстановленную очередь. Совместимые контрольные точки используются повторно. После изменения модели, языка или файла следуйте подсказке.

Что проверить при завершении с предупреждением?

Проверьте метки качества, сомнительные фрагменты, строки без перевода и важные реплики.

Как сообщить об ошибке?

Укажите архитектуру, версию, этап и шаги воспроизведения. Удалите имена файлов, пути, субтитры и ключи из журналов. GitHub Issues ↗
