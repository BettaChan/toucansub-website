1.2.02

2026-11-12
รุ่น 1.2.02

ขนาดแพ็กเกจ สิทธิ์ใช้งาน และรันไทม์

  • ลดขนาดรันไทม์ทั้งสองแพลตฟอร์ม โดยเก็บการถอดเสียงและเครื่องมือวินิจฉัย
  • เพิ่มสิทธิ์ใช้งานแอป ประกาศของบุคคลที่สาม และเอกสารซอร์ส FFmpeg ที่เกี่ยวข้อง
  • Windows x64 ใช้ Visual C++ x64 ของระบบและมีเครื่องมือวินิจฉัยเอนจิน
  • ย้ายคิวไว้เหนือรายละเอียดงาน และพับบันทึกไปทางขวาได้
  • เพิ่มการตรวจสอบอัปเดตด้วยตนเองในเมนูวิธีใช้ → เกี่ยวกับ

แอป macOS ลงนามแบบ ad hoc และยังไม่ผ่านการรับรองจาก Apple แพ็กเกจ Windows ผ่านการทดสอบแล้วและยังไม่ได้ลงนาม
