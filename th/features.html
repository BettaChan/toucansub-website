แปลคำบรรยาย

เลือกภาษาปลายทาง เทียบทั้งสองฉบับบนไทม์ไลน์ และเลือกส่งออกต้นฉบับด้วยได้

สำหรับวิดีโอต่างภาษาและงานสองภาษา

พื้นที่ทำงาน

จัดการหลายไฟล์ในหน้าจอเดียว

  • เพิ่มไฟล์หรือโฟลเดอร์เข้าคิว
  • ดูความคืบหน้าและตัวอย่างคำบรรยาย
  • งานยาวแบ่งเป็นช่วงและทำต่อจากจุดที่เข้ากันได้
  • ตรวจสอบทรัพยากร คำเตือน และบันทึก

โมเดลและการตรวจสอบระบบ

ตั้งค่าโมเดลถอดเสียงและโมเดลภาษาแยกกัน

แอปไม่ได้มาพร้อมโมเดลภาษาขนาดใหญ่ หากต้องการปรับข้อความหรือแปลคำบรรยาย ให้ติดตั้ง Ollama และดาวน์โหลดโมเดล หรือใช้คีย์ API ของคุณเองจากบริการคลาวด์ที่เข้ากันได้กับ OpenAI

การถอดเสียงใช้ไฟล์น้ำหนัก Whisper ที่ดาวน์โหลดแยกต่างหาก โดยไม่ต้องใช้ Ollama หรือคีย์ API

ตรวจสอบสภาพแวดล้อม เอนจิน น้ำหนัก และโมเดลภาษาในการตั้งค่า
