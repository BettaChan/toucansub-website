คู่มือ

สร้างคำบรรยาย ชุดแรกของคุณ

ติดตั้งแอป เตรียมโมเดล Whisper แล้วนำเข้าไฟล์เสียงหรือวิดีโอ

ติดตั้งแอปตรวจสอบไฟล์เตรียมโมเดลสร้างคำบรรยายข้อมูลและความเป็นส่วนตัวคำถามที่พบบ่อย

ติดตั้งแอป

ดูแพลตฟอร์มที่รองรับและสถานะเวอร์ชันในหน้าดาวน์โหลด ดาวน์โหลด ↗

macOS Apple Silicon

เปิด DMG ที่ได้รับแล้วลากแอปไปยัง Applications หรือแตกไฟล์ ZIP และย้ายแอปไปยังโฟลเดอร์เดียวกัน

Windows x64

เปิดตัวติดตั้ง EXE หรือแตก ZIP ทั้งหมดแล้วเปิดแอป หาก Windows แจ้งว่าขาด Visual C++ x64 ให้ติดตั้งหรือซ่อมแซมรันไทม์

ดาวน์โหลดรันไทม์จาก Microsoft ↗

ตรวจสอบไฟล์

เปลี่ยนชื่อไฟล์ตัวอย่างเป็นชื่อจริง แล้วเทียบผลลัพธ์กับรายการ SHA-256 จาก GitHub Release เดียวกัน

macOS

shasum -a 256 "installer.dmg"

Windows PowerShell

Get-FileHash "installer.exe" -Algorithm SHA256

เตรียมโมเดล

  1. เปิดการตั้งค่าการถอดเสียง แล้วเลือกเอนจินและขนาดโมเดล
  2. ดาวน์โหลดโมเดลและรอให้เสร็จ
  3. เปิดการตรวจสอบระบบเพื่อดูว่าสภาพแวดล้อม เอนจิน และน้ำหนักพร้อมใช้งาน

ตั้งค่าโมเดลสำหรับปรับข้อความหรือแปล

แอปไม่ได้มาพร้อมโมเดลภาษาขนาดใหญ่ หากต้องการปรับข้อความหรือแปลคำบรรยาย ให้ติดตั้ง Ollama และดาวน์โหลดโมเดล หรือใช้คีย์ API ของคุณเองจากบริการคลาวด์ที่เข้ากันได้กับ OpenAI

กรอกชื่อโมเดลสำหรับ Ollama บนเครื่อง หรือกรอก Base URL, API Key และชื่อโมเดลสำหรับบริการที่เข้ากันได้กับ OpenAI หากถอดเสียงอย่างเดียว ใช้เพียง Whisper

การถอดเสียงใช้ไฟล์น้ำหนัก Whisper ที่ดาวน์โหลดแยกต่างหาก โดยไม่ต้องใช้ Ollama หรือคีย์ API

สร้างคำบรรยาย

  1. กลับไปยังพื้นที่ทำงานและเพิ่มไฟล์หรือโฟลเดอร์
  2. เลือกถอดเสียง ปรับข้อความ หรือแปล หากแปลให้เลือกภาษาปลายทาง
  3. เริ่มประมวลผลและติดตามความคืบหน้า หากระบบถาม ให้ยืนยันภาษาจริงของสื่อ
  4. ตรวจสอบตัวอย่าง แล้วเปิดไฟล์ SRT ในโฟลเดอร์สื่อ

ข้อมูลและความเป็นส่วนตัว

ถอดเสียงบนเครื่อง

แอปอ่านสื่อ แยกเสียง และใช้ Whisper บนคอมพิวเตอร์ การดาวน์โหลดน้ำหนักครั้งแรกต้องใช้อินเทอร์เน็ต

ปรับข้อความและแปลที่ไหน

ข้อความคำบรรยายถูกส่งไปยังปลายทางที่ตั้งค่าไว้ Ollama บนเครื่องจะประมวลผลในคอมพิวเตอร์ ส่วนบริการระยะไกลใช้กฎการประมวลผลและการเก็บข้อมูลของผู้ให้บริการ

ตัวอย่างบนเว็บไซต์

หน้าแรกใช้ตัวอย่างสำเร็จรูปและไม่มีช่องอัปโหลดสื่อ

คำถามที่พบบ่อย

ต้องใช้ Ollama เพื่อสร้างคำบรรยายต้นฉบับหรือไม่

เลือกถอดเสียงอย่างเดียวและดาวน์โหลดน้ำหนัก Whisper ที่ต้องการ

ทำอย่างไรหาก Windows แจ้งว่าขาดรันไทม์

ตรวจสอบ Visual C++ x64 และใช้ support/diagnose-engine.cmd ในโฟลเดอร์แอปเพื่อตรวจสอบส่วนประกอบที่ต้องใช้

จะทำงานที่หยุดไปต่อได้อย่างไร

เปิดพื้นที่ทำงานอีกครั้งและดูคิวที่กู้คืน ระบบใช้จุดบันทึกที่เข้ากันได้ หากเปลี่ยนโมเดล ภาษา หรือไฟล์ ให้ทำตามข้อความแจ้งเตือน

ต้องตรวจอะไรเมื่อเสร็จพร้อมคำเตือน

ตรวจเครื่องหมายคุณภาพ ช่วงที่ไม่แน่ใจ ข้อความที่ยังเป็นต้นฉบับ และบทพูดสำคัญ

จะแจ้งปัญหาอย่างไร

ระบุสถาปัตยกรรมระบบ เวอร์ชัน ขั้นตอน และวิธีทำให้เกิดปัญหาซ้ำ ลบชื่อสื่อ พาธ ข้อความ และคีย์จากบันทึกก่อนส่ง GitHub Issues ↗
