使用指南

產生你的 第一份字幕。

安裝應用程式、準備 Whisper 模型，然後匯入音訊或影片。

安裝應用程式驗證檔案準備模型產生字幕資料與隱私常見問題

安裝應用程式

在下載中心查看支援平台與版本狀態。 下載 ↗

macOS Apple Silicon

取得安裝檔後，開啟 DMG 並把應用程式拖入「應用程式」資料夾，或解壓縮 ZIP 後移入該資料夾。

Windows x64

執行 EXE 安裝程式，或完整解壓縮 ZIP 後啟動大嘴鳥字幕。若 Windows 提示缺少 Visual C++ x64 執行階段，請安裝或修復。

Microsoft 官方執行階段下載 ↗

驗證檔案

將指令中的檔名換成實際檔名，並與同一 GitHub Release 的 SHA-256 清單比對。

macOS

shasum -a 256 "installer.dmg"

Windows PowerShell

Get-FileHash "installer.exe" -Algorithm SHA256

準備模型

  1. 開啟「設定 → 語音轉錄」，選擇引擎與模型大小。
  2. 下載轉錄模型，等待權重下載完成。
  3. 開啟健康檢查，確認執行環境、引擎與權重均可用。

設定潤飾與翻譯模型

安裝檔未內建大型語言模型。 字幕潤飾與翻譯需自行安裝 Ollama 並下載模型，或自備支援 OpenAI 相容介面的雲端服務 API 金鑰。

使用本機 Ollama 時填寫模型名稱，使用 OpenAI 相容服務時填寫 Base URL、API Key 與模型名稱。僅轉錄只需 Whisper。

僅轉錄使用另行下載的 Whisper 權重，無需 Ollama 或 API 金鑰。

產生字幕

  1. 返回工作台，加入檔案或資料夾。
  2. 選擇僅轉錄、原文潤飾或翻譯字幕，翻譯時選擇目標語言。
  3. 開始批次並查看進度。若出現來源語言提示，請確認素材的實際語言。
  4. 完成後檢查字幕預覽，再到媒體所在資料夾查看 SRT。

資料與隱私

本機轉錄

應用程式在電腦上讀取素材、擷取音訊並執行 Whisper。首次下載權重需要網路。

潤飾與翻譯在哪裡執行

字幕文字會傳至你設定的模型端點。本機 Ollama 會在電腦上處理，遠端服務則依服務商的處理與留存規則運作。

官網示範

首頁使用固定範例，頁面沒有媒體上傳功能。

常見問題

只產生原語言字幕，需要 Ollama 嗎？

選擇僅轉錄，下載所需的 Whisper 權重即可。

Windows 提示缺少執行階段怎麼辦？

檢查 Visual C++ x64 執行階段。應用程式資料夾內的 support/diagnose-engine.cmd 可檢查引擎相依元件。

如何繼續中斷的任務？

重新開啟工作台，查看已還原的佇列。應用程式會沿用相容的中斷點。若模型、來源語言或檔案有變動，請依提示繼續或重做。

任務完成但有警告時該檢查什麼？

查看品質標記、不確定片段、仍保留原文的項目與重要對白。

如何回報問題？

請附上系統架構、版本、任務階段與重現步驟。分享記錄前先移除素材名稱、路徑、字幕文字與金鑰。 意見回饋與支援 ↗ · GitHub Issues ↗
